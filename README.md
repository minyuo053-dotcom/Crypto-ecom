# CryptoMart

## Project Overview

CryptoMart is a comprehensive e-commerce platform designed for secure cryptocurrency transactions. The project aims to facilitate the buying and selling of products using various cryptocurrencies while ensuring buyer protection through an escrow mechanism and seller trust via KYC compliance. This platform supports the top 20 cryptocurrencies, enabling users to transact with their preferred digital assets.

### Key Features
- Multi-crypto wallet functionality
- Escrow release mechanism ensuring buyer protection
- KYC certification process for sellers
- Support for top 20 cryptocurrencies including Bitcoin, Ethereum, and others

### Technologies Used
- Smart Contracts (Solidity)
- Backend (Node.js, Express)
- Frontend (React, Redux)
- Database (MongoDB)
- Blockchain Interactions (Web3.js)

### Installation
1. Clone the repository: `git clone https://github.com/minyuo053-dotcom/Crypto-ecom`
2. Navigate to project directory: `cd Crypto-ecom`
3. Install dependencies for backend: `cd backend && npm install`
4. Install dependencies for frontend: `cd frontend && npm install`

### Usage
- Start the backend server: `npm start`
- Launch the frontend application: `npm start`
